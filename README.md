Student Marks Analyzer

📌 Project Description

Student Marks Analyzer is a simple C++ mini project that analyzes students' marks and displays their academic performance.

The program takes marks from users and calculates the total, average, highest mark, lowest mark, and the number of passed and failed students.

🚀 Features

- Accepts marks for multiple students.
- Validates the number of students (1–100).
- Validates marks (0–100).
- Calculates total marks.
- Calculates average marks.
- Finds the highest mark.
- Finds the lowest mark.
- Counts passed students (40 or above).
- Counts failed students.
- Allows users to analyze marks again.

🛠️ Technologies Used

- Programming Language: C++
- Header File: iostream
- Concepts Used:
  - Arrays
  - Functions
  - Loops
  - Conditional Statements
  - User Input and Output

💻 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code or any C++ IDE.
3. Compile the C++ source file.

g++ main.cpp -o analyzer

4. Run the program.

./analyzer

For Windows:

analyzer.exe
